# Music research data package 2.1
Based on the previously validated V2, with 222,550 observations; no new upstream ingestion. The V2 relational tables remain intact.
New tables: `entity_names_v21.csv`, `entity_aliases_v21.csv`, `performance_names_v21.csv`; browser dictionary `runtime/names_v21.json`.
A shared Wikidata QID or an existing V2 entity ID is required for automatic identity consolidation. Similar strings alone never authorize merging. Hebrew and English labels remain empty if no source-provided label exists. Aliases are searchable but do not imply verified translations. Each participant in a collaborative artist credit receives fractional attribution (1 / credited entity count) for additive metrics to prevent double counting. Spotify streams and YouTube views must not be added as a common unit. Suspected duplicated YouTube observations are excluded by default. Missing coverage is not zero. Source labels are derived from the existing catalog, not live Wikidata queries.
