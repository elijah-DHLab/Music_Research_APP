# Music Research — UI maintenance release 2.2 / גרסת תחזוקה 2.2

## הפעלה
חלצו את ה-ZIP ופתחו `index.html`. קובצי התצוגה הדרושים מוטמעים ב-HTML, וקובצי ה-V2.1 הנוספים נמצאים בתוך `data/v2/`.

## מה השתנה
- עיצוב כהה וכל 11 מסכי המחקר נשמרו.
- מסננים נפתחים בתוך הזרימה של הדף; אפשר לחפש בתפריט ולבחור/לנקות פריטים גלויים.
- רשימת הסדרות הופיעה בעבר מעל הגרף; היא נמצאת כעת מתחתיו.
- כפתור איפוס כולל מחזיר תקופות, מסננים, בחירות, זום, שאלות וחיפוש לברירות מחדל. האיפוס אינו מוחק קובצי נתונים או הכרעות מחקריות.
- בקיטלוג הביצועים ובפירוט התצפיות מופיעים קישורים ישירים ל-Spotify ול-YouTube כשיש מזהה פלטפורמה תקין. מדובר בקישור להקלטה/סרטון ולא לשחזור היסטורי מדויק של דף הדירוג.

## מקור נתונים ומגבלות
גרסת 2.1 המעובדת נשמרה ללא שינוי. 7,960 תצפיות YouTube חשודות משוכפלות עדיין מוחרגות כברירת מחדל. היעדר נתונים אינו אפס. זיהוי יצירות וביצועים הוא בחלקו ראשוני. הקישורים למקורות אינם אימות אוטומטי של התאמה בין ביצועים.

## בדיקות
בדיקת תחביר JavaScript, ניווט בכל 11 מסכי המערכת, סינון/חיפוש/איפוס, פתיחת ציר זמן ופירוט שירים, קישורים למקורות ובדיקה נפרדת במובייל דרך Chromium בהרצה מבודדת של HTML. בדיקת פרסום חיצוני ב-GitHub Pages לא בוצעה.
